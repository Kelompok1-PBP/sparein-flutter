# M3 Panduan Perbaikan

**Penanggung jawab**

Hanna Zerlina Razaq Putri Wicaksono (2506594692)

Modul ini akan menampilkan ringkasan, peringatan keselamatan, dan langkah
perbaikan perangkat. Pengunjung dapat membaca ringkasan panduan. Pengguna
yang sudah masuk ke akun dapat melihat langkah perbaikan lengkap.

## Tahap awal

Pilih tab **Panduan** di bilah navigasi bawah. Halaman kosong akan terbuka
dengan judul **Panduan Perbaikan**.

Pada tahap berikutnya, modul akan mengambil data panduan dari Django
melalui `/api/v1/guides/`.
